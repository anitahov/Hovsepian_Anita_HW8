# Homework 8 — Anita Hovsepian

## Structure
- `notebooks/Hovsepian_Anita_HW8.ipynb`: homework notebook
- `data/`: both required datasets
- `requirements.txt`: Python dependencies

## Run
From the repository root:

```bash
python -m pip install -r requirements.txt
cd notebooks
jupyter notebook Hovsepian_Anita_HW8.ipynb
```

Run all cells in order. The notebook also supports starting Jupyter from the repository root. The Monte Carlo simulations may take a long time. In Google Colab, the notebook alone is insufficient: the `data/` folder must be available in the runtime at the expected relative path.
